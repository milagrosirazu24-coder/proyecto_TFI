## Descripción del Sistema
**Perfumería Carmelí** es un microemprendimiento comercial enfocado en la comercialización y fraccionamiento personalizado de fragancias finas (presentaciones de 10 ml y 100 ml). El proyecto de software asociado comprende el desarrollo de un sistema web modular (Front-End de catálogo e interfaz de usuario, y Back-End de gestión de inventario y ventas) conectado a una base de datos en la nube (Supabase), automatizando el flujo de compras, la validación de stock en tiempo real y el control logístico.
